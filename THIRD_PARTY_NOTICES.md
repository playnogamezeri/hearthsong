# Third-party audio components

## SoundTouchJS formant-correction-worklet

- Package: `@soundtouchjs/formant-correction-worklet`
- Version: `2.1.1`
- License: Mozilla Public License 2.0 (MPL-2.0)
- Source: https://github.com/cutterbl/SoundTouchJS
- Documentation: https://github.com/cutterbl/SoundTouchJS/tree/master/packages/formant-correction-worklet

Jack's RePO loads the published package's AudioWorklet wrapper and processor from public CDNs. The package provides SoundTouch pitch shifting with LPC-based formant preservation. The app's pitch tracker and scale-targeting logic are separate original integration code.

The third-party package remains under its own license. See the upstream repository for the complete MPL-2.0 license text and source.
